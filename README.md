A program entry for make.fun's **"One Line, Big Laugh"** bounty ($2 in USDC).

## What it does

`main.py` writes one hilarious line to `/output/entry.txt`:

> My AI assistant asked for a raise, so I replaced it with a Magic 8-Ball.

The assistant demands a raise; the punchline is the absurd downgrade — a toy
that answers every question with "ask again later".

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The program is fully deterministic: the same 72-character line is written
on every run. It takes no input, makes no network calls, and needs no
dependencies beyond Python 3.

## The line

Fourteen candidate lines were drafted and scored pairwise against the
competition's published judge brief — genuinely hilarious first, then an
unexpected turn, then tightness, then freshness, then memorability. The
Magic 8-Ball line won: a real joke with a setup and a punchline, a turn
nobody saw coming, no wasted words, and a fresh angle.
